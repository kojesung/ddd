### 입력 처리

-   [x] 월과 해당 월의 시작 요일을 입력한다.
-   [x] 평일 근무 사원 리스트를 입력한다.
-   [x] 주말 근무 사원 리스트를 입력한다.

### 입력 파싱

-   [x] 평일, 주말 각 근무 리스트에는 각 1회씩만 들어가도록 하고 그렇지 않으면 ERROR를 반환한다.
-   [x] 월과 해당 월의 시작 요일을 잘못된 형태로 입력했을 때 재입력하도록 처리한다
-   [x] 월과 해당 월의 시작 요일을 입력하면 {월:n, 요일:m(index 형태)}로 반환한다.
-   [ ] 평일, 주말 근무 사원 리스트를 입력하다 에러가 발생한 경우 평일 근무 사원부터 재입력하도록 처리한다.
-   [x] 각 사원의 닉네임은 최대 5글자로 제한한다.
-   [ ] 사원은 총 35명으로 제한한다.
-   [x] 각 사원 배열은 문자열을 담고 있는 배열로 반환한다.

### Calendar class

-   [ ] 입력 받은 월과 해당 월의 시작 요일로 해당 달의 Calendar class를 구성한다.
-   [ ] 입력 받은 대로 근무자를 배치한다.
    -   [ ] 근무표를 배치하는 과정에서 연속된 근무자가 있을 시 도메인 규칙에 맞도록 수정한다.
-   [ ] 해당 달의 특정 일을 인자로 전달했을 때 무슨 요일인지 반환하는 메서드
-   [ ] 해당 달의 특정 일을 인자로 전달했을 때 법정 공휴일인지 반환하는 메서드
-   [ ] 정리된 전체 근무표를 반환하는 메서드
